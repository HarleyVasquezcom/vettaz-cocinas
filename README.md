# Vettaz Cocinas Integrales 🍳✨

Sitio web oficial y catálogo interactivo de **Vettaz Cocinas Integrales**, empresa colombiana especializada en diseño 3D, fabricación e instalación de cocinas integrales, closets, muebles de baño y centros de entretenimiento a medida en Bogotá y Cundinamarca.

---

## 🎨 Sistema de Diseño

- **Header y Navbar**: Fondo Azul Agua-Marina (`#0097A7`) con navegación sticky responsiva.
- **Botones CTA**: Naranja Vettaz (`#F5A000`) con hover accesible (`#E08C00`).
- **Footer**: Azul Agua-Marina Oscuro (`#006978`).
- **Tipografía**:
  - Encabezados: `Playfair Display`, serif.
  - Subtítulos / Script: `Dancing Script`, cursive.
  - Cuerpo de texto: `Lato`, sans-serif.

## 🚀 Tecnologías e Integraciones

- **HTML5 Semántico**: Para máxima accesibilidad e indexación SEO.
- **CSS3 Moderno**: CSS Custom Properties (Variables) para theming y Flexbox/Grid layouts.
- **JavaScript Vanilla**: Lógica rápida sin dependencias pesadas.
- **Swiper.js**: Carruseles y galerías deslizables de productos.
- **GLightbox**: Visualización de proyectos en pantalla completa.
- **AOS (Animate On Scroll)**: Animaciones al desplazar la página.
- **Font Awesome 6**: Iconografía profesional.
